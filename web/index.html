دستیار آموزشی آفلاین

دستیار به‌صورت آفلاین آماده است. پس از استقرار سرور امن روی HTTPS و تنظیم کلید API در پنل میزبان، نشانی پایه سرور را اینجا ذخیره کن تا پرسش‌ها به مدل آنلاین فرستاده شوند. کلید API را هرگز در این صفحه وارد نکن.

این توکن فقط برای احراز دسترسی به سرور است؛ کلید OpenAI را اینجا وارد نکن. توکن در نسخه پشتیبان عمومی صادر نمی‌شود.

حالت فعلی: آفلاین؛ با ذخیره سرور معتبر، اتصال آنلاین آزمایش می‌شود.
سلام قهرمان! 😊 من دستیار آموزشی آموزش با امیر هستم. اگر اتصال سرور و کلید API فعال باشد، به هوش مصنوعی آنلاین وصل می‌شوم؛ در غیر این صورت از راهنمای آفلاین استفاده می‌کنم. مثلاً بپرس: «الگوی عددی چیست؟» یا «قانون بخش‌پذیری بر ۳ را توضیح بده.»

برنامه‌ریزی و برگزاری کلاس آنلاین

مدیریت جلسه

جلسه را زمان‌بندی کن، لینک Google Meet یا Zoom را ذخیره کن و در زمان مقرر وارد کلاس شو. برای ساخت اتاق Meet ابتدا دکمه زیر را بزن و لینک ساخته‌شده را در کادر وارد کن.

توجه: این نسخه زمان‌بندی، نگهداری لینک، دعوت و ورود به جلسه را مدیریت می‌کند؛ تماس تصویری داخل خود برنامه میزبانی نمی‌شود. برای کلاس زنده از سرویس Meet یا Zoom استفاده می‌شود. اطلاعات جلسات فعلاً فقط روی همین دستگاه ذخیره می‌شوند.

تکلیف‌های کلاسی

تحلیل نقاط ضعف

پس از پاسخ‌دادن به سؤال‌ها، مبحث‌هایی که بیشتر به تمرین نیاز دارند اینجا نمایش داده می‌شوند.

پشتیبان‌گیری و بازیابی

از اطلاعات ذخیره‌شده روی همین دستگاه یک نسخه پشتیبان JSON بگیر یا فایل پشتیبان قبلی را برگردان. این فایل ممکن است شامل نام دانش‌آموزان و یادداشت‌های آموزشی باشد؛ آن را خصوصی نگه دار.
