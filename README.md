# آموزش با امیر — نسخه ۲.۱.۰

سامانه آموزشی فارسی، راست‌چین و موبایل‌محور با قابلیت نصب به‌صورت PWA و بسته‌بندی اندروید با Capacitor.

## وضعیت محتوای آموزشی

- ریاضی ششم: نقشه هر ۷ فصل مطابق سرفصل کتاب درسی.
- ۲۹ درس مستقل در هفت فصل: عدد و الگوهای عددی، کسر، اعداد اعشاری، تقارن و مختصات، اندازه‌گیری، تناسب و درصد، تقریب.
- آزمونک مستقل برای درس‌ها و آزمون جامع چندفصلی.
- کاربرگ‌ساز قابل چاپ با سطح‌بندی آسان، متوسط و چالشی برای الگوها، عددنویسی، بخش‌پذیری، اعداد صحیح، کسرها، اندازه‌گیری، تناسب و درصد و تقریب.
- بازیگاه ریاضی، وایت‌برد لمسی، دفتر یادداشت، ثبت پیشرفت و تحلیل نقاط ضعف.

**محدوده فعلی:** محتوای کامل برنامه در این مرحله بر ریاضی پایه ششم متمرکز است. کتاب‌های سایر پایه‌ها، سایر درس‌های ابتدایی و دوره‌های زبان انگلیسی هنوز باید به‌صورت مرحله‌ای اضافه و بازبینی شوند. درس‌نامه‌ها تألیفی‌اند و متن کتاب درسی را بازنشر نمی‌کنند.

## پنل معلم و کلاس آنلاین

- فهرست محلی دانش‌آموزان پایه اول تا ششم، جست‌وجو، ویرایش و ثبت نیاز آموزشی.
- ثبت تکلیف برای یک دانش‌آموز یا کل کلاس، گزارش و خروجی CSV/JSON.
- زمان‌بندی کلاس با تاریخ، ساعت، مدت، موضوع و پایه مخاطب؛ نگهداری لینک Google Meet یا Zoom؛ ارسال دعوت و ورود به جلسه.
- حضور و غیاب هر جلسه برای دانش‌آموزان پایه هدف با وضعیت حاضر، غایب و غیبت موجه؛ گزارش خلاصه و خروجی CSV مستقل.
- داشبورد خلاصه تعداد دانش‌آموزان، تکالیف در انتظار، جلسات و نرخ حضور ثبت‌شده.
- جلسه تصویری در این نسخه داخل برنامه میزبانی نمی‌شود؛ برای پخش زنده از سرویس Meet یا Zoom استفاده می‌شود.
- داده‌های دانش‌آموزان، تکلیف‌ها، جلسات و حضور و غیاب فعلاً روی همان دستگاه ذخیره می‌شوند؛ حساب مستقل دانش‌آموز و همگام‌سازی ابری فعال نیست.

## اجرای کنترل کیفیت

با Node.js نسخه ۲۰ یا ۲۲:

```bash
npm install
npm run qa
npm --prefix secure-ai-server install
npm --prefix secure-ai-server test
```

آزمون QA ساختار PWA و Capacitor، همگام بودن فایل‌های ریشه و پوشه web، وجود ۲۹ درس و بانک آزمون، بانک‌های کاربرگ و نحو اسکریپت اصلی، بانک آزمون تمام درس‌ها، حضور و غیاب و ابزارهای مدیریت کلاس را بررسی می‌کند. این آزمون جایگزین تست واقعی روی دستگاه اندرویدی نیست.

## ساخت APK آزمایشی

Workflow در مسیر **Actions → Android Debug APK** اجرا می‌شود. خروجی APK آزمایشی در بخش Artifacts همان اجرا قرار می‌گیرد. این APK امضای انتشار فروشگاهی ندارد.

## منابع برنامه درسی

- [پایگاه رسمی کتاب‌های درسی](https://chap.sch.ir)
- [معرفی کتاب ریاضی ششم در شبکه رشد](https://www.roshd.ir/riazi/Content/کتاب-ریاضی-ششم-دبستان)

ساختار هفت‌فصلی با فهرست کتاب ریاضی ششم تطبیق داده شده است. پیش از انتشار عمومی، محتوا باید صفحه‌به‌صفحه با نسخه رسمی سال تحصیلی جاری ویرایش و بازبینی نهایی شود.

## حریم خصوصی و محدودیت‌ها

- داده‌های دانش‌آموز، گزارش‌ها، یادداشت‌ها و جلسات در حافظه محلی دستگاه نگهداری می‌شوند.
- فایل پشتیبان JSON ممکن است شامل نام دانش‌آموز و یادداشت آموزشی باشد؛ آن را خصوصی نگه دارید.
- دستیار هوشمند در حالت پیش‌فرض آفلاین است. اگر مدیر برنامه سرور هوش مصنوعی را فعال و تنظیم کند، متن پرسش‌ها به سرویس بیرونی پیکربندی‌شده ارسال می‌شود.
- فونت Vazirmatn از Google Fonts بارگیری می‌شود.
- پیش از انتشار در بازار، سیاست حریم خصوصی عمومی، اطلاعات پشتیبانی، بررسی مجوزها و دسترسی‌های اندروید و تست امنیتی باید تکمیل شوند.

## انتشار در بازار

آماده‌سازی فروشگاه Google Play فعلاً خارج از محدوده است. انتشار در کافه‌بازار را پس از تکمیل آزمون دستگاه واقعی، ساخت نسخه Release امضاشده، آماده‌سازی تصاویر و توضیحات فروشگاه، سیاست حریم خصوصی و بررسی الزامات محتوای کودک انجام می‌دهیم.
