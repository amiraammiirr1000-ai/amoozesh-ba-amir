# سرور امن دستیار هوشمند آموزش با امیر

این نمونه فقط اسکلت بک‌اند است؛ تا وقتی روی سرور HTTPS مستقر و کلید معتبر در متغیر محیطی قرار نگیرد، دستیار آنلاین فعال نمی‌شود. کلید را هرگز در HTML، اپ اندروید یا مخزن عمومی قرار نده.

مدل پیش‌فرض `gpt-4.1-mini` است و می‌توان آن را با `OPENAI_MODEL` تغییر داد. دسترسی مدل را در حساب API بررسی کن.

## اجرا
1. Node.js نسخه LTS نصب باشد.
2. در این پوشه `npm install` اجرا کن.
3. متغیر محیطی `OPENAI_API_KEY` را در محیط سرور تنظیم کن (فایل `.env` در این بسته وجود ندارد؛ کلید را داخل کد ننویس).
4. `npm start` را اجرا کن و مسیر `/health` را بررسی کن.
5. سرور را پشت HTTPS و با محدودیت مصرف/هزینه مستقر کن.

پیش از استفاده واقعی باید CORS (متغیر APP_ORIGIN)، احراز هویت معلم/دانش‌آموز، ثبت رضایت، سیاست نگهداری داده و محدودیت‌های هزینه بر اساس میزبان نهایی تنظیم شوند. این اسکلت جایگزین استقرار امن و تست امنیتی نیست.


## استقرار سریع با Render

فایل `render.yaml` در ریشه مخزن برای ساخت سرویس وب آماده شده است.

1. در Render گزینه **New → Blueprint** را انتخاب و مخزن GitHub همین پروژه را متصل کن.
2. Render سرویس `amoozesh-ba-amir-ai` را از روی `render.yaml` می‌سازد. متغیر `TUTOR_ACCESS_TOKEN` به‌صورت خودکار و امن تولید می‌شود.
3. یک ارائه‌دهنده API سازگار با OpenAI انتخاب کن و کلیدش را فقط در Environment سرویس Render در متغیر `OPENAI_API_KEY` قرار بده.
4. اگر ارائه‌دهنده آدرس سازگار اختصاصی دارد، آن را در `OPENAI_BASE_URL` بگذار؛ نام مدل دقیق همان ارائه‌دهنده را در `OPENAI_MODEL` ثبت کن. برای API خود OpenAI، `OPENAI_BASE_URL` را خالی بگذار.
5. پس از Deploy، آدرس سرویس را با مسیر `/health` آزمایش کن. مقدار `configured` باید `true` و `accessProtected` نیز `true` باشد.
6. آدرس اصلی سرویس را در صفحه «معلم هوشمند امیر» برنامه ذخیره و آزمایش کن. توکن تولیدشده را فقط در فیلد «توکن دسترسی خصوصی» همان برنامه وارد کن؛ کلید ارائه‌دهنده را هرگز در برنامه یا GitHub ننویس.

### انتخاب ارائه‌دهنده و هزینه

این سرور از قالب **OpenAI-compatible Chat Completions** پشتیبانی می‌کند؛ بنابراین می‌توان از OpenAI یا یک سرویس سازگار دیگر (از جمله سرویس‌دهنده‌های دارای API سازگار و مدل‌های رایگان/سهمیه‌دار) استفاده کرد. رایگان بودن، سهمیه و دسترسی جغرافیایی را باید در حساب همان ارائه‌دهنده بررسی کرد. سرویس Render در پلن رایگان ممکن است پس از بی‌کاری به خواب برود و پاسخ اول با تأخیر بیاید.

**نکته ضروری:** حساب ChatGPT به‌خودی‌خود کلید API یا اعتبار مصرف API ایجاد نمی‌کند. برای پاسخ آنلاین واقعی، یک کلید API معتبر از ارائه‌دهنده‌ای که در محل استفاده مجاز و در دسترس است لازم است. اگر کلید یا سرویس‌دهنده در دسترس نباشد، برنامه فقط پاسخ‌گوی آفلاین محدود خود را ارائه می‌کند؛ آن را هوش مصنوعی آنلاین معرفی نمی‌کند.
