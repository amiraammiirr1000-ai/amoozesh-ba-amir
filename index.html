دستیار آموزشی آفلاین

دستیار به‌صورت آفلاین آماده است. پس از استقرار سرور امن روی HTTPS و تنظیم کلید API در پنل میزبان، نشانی پایه سرور را اینجا ذخیره کن تا پرسش‌ها به مدل آنلاین فرستاده شوند. کلید API را هرگز در این صفحه وارد نکن.

این توکن فقط برای احراز دسترسی به سرور است؛ کلید OpenAI را اینجا وارد نکن. توکن در نسخه پشتیبان عمومی صادر نمی‌شود.

حالت فعلی: آفلاین؛ با ذخیره سرور معتبر، اتصال آنلاین آزمایش می‌شود.
سلام قهرمان! 😊 من دستیار آموزشی آموزش با امیر هستم. اگر اتصال سرور و کلید API فعال باشد، به هوش مصنوعی آنلاین وصل می‌شوم؛ در غیر این صورت از راهنمای آفلاین استفاده می‌کنم. مثلاً بپرس: «الگوی عددی چیست؟» یا «قانون بخش‌پذیری بر ۳ را توضیح بده.»
