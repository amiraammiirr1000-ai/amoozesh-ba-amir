# سرور امن دستیار هوشمند آموزش با امیر

این نمونه فقط اسکلت بک‌اند است؛ تا وقتی روی سرور HTTPS مستقر و کلید معتبر در متغیر محیطی قرار نگیرد، دستیار آنلاین فعال نمی‌شود. کلید را هرگز در HTML، اپ اندروید یا مخزن عمومی قرار نده.

مدل پیش‌فرض `gpt-4.1-mini` است و می‌توان آن را با `OPENAI_MODEL` تغییر داد. دسترسی مدل را در حساب API بررسی کن.

## اجرا
1. Node.js نسخه LTS نصب باشد.
2. در این پوشه `npm install` اجرا کن.
3. متغیر محیطی `OPENAI_API_KEY` را در محیط سرور تنظیم کن (فایل `.env` در این بسته وجود ندارد؛ کلید را داخل کد ننویس).
4. `npm start` را اجرا کن و مسیر `/health` را بررسی کن.
5. سرور را پشت HTTPS و با محدودیت مصرف/هزینه مستقر کن.

پیش از استفاده واقعی باید CORS (متغیر APP_ORIGIN)، احراز هویت معلم/دانش‌آموز، ثبت رضایت، سیاست نگهداری داده و محدودیت‌های هزینه بر اساس میزبان نهایی تنظیم شوند. این اسکلت جایگزین استقرار امن و تست امنیتی نیست.
