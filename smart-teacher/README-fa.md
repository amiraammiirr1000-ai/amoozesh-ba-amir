# راه‌اندازی معلم هوشمند آنلاین

این پوشه یک Worker امن برای اتصال «معلم هوشمند امیر» به OpenAI Responses API دارد. کلید API فقط در تنظیمات محرمانه Cloudflare نگهداری می‌شود و هرگز داخل کد وب یا مخزن قرار نمی‌گیرد.

## ۱) ساخت Worker
1. در Cloudflare وارد Workers & Pages شوید و یک Worker جدید بسازید.
2. محتوای فایل `worker.js` را در ویرایشگر Worker قرار دهید و Deploy کنید.
3. نشانی Worker را یادداشت کنید؛ مانند `https://your-worker.your-subdomain.workers.dev`.

## ۲) ثبت متغیرهای محرمانه
در Worker → Settings → Variables and Secrets این موارد را اضافه کنید:
- Secret با نام `OPENAI_API_KEY`: کلید API شخصی OpenAI.
- Secret با نام `APP_ACCESS_TOKEN`: یک رمز طولانی و تصادفی که فقط مدیر برنامه می‌داند.
- (اختیاری) متغیر متنی `AI_MODEL`: مقدار `gpt-4.1-mini`.

کلید API را در فایل‌ها، پیام‌ها یا صفحه برنامه قرار ندهید.

## ۳) اتصال در برنامه
1. برنامه «آموزش با امیر» را باز کنید.
2. بخش «معلم هوشمند امیر» را باز کنید.
3. نشانی Worker را در «نشانی پایه سرور» وارد و ذخیره کنید.
4. همان رمز `APP_ACCESS_TOKEN` را در قسمت توکن دسترسی خصوصی وارد و ذخیره کنید.
5. «آزمایش اتصال» را بزنید. باید پیام آماده‌بودن سرور را ببینید.

## مسیرهای API
- `GET /health`: وضعیت پیکربندی را اعلام می‌کند، نه خود کلید را.
- `POST /api/tutor`: بدنه `{"question":"..."}` می‌گیرد و `{"answer":"...","mode":"online"}` برمی‌گرداند.

## امنیت و هزینه
- کلید OpenAI فقط سمت Worker است.
- دسترسی با توکن اختیاری نیست؛ برای استفاده عمومی حتماً `APP_ACCESS_TOKEN` را تنظیم کنید.
- هر پرسش آنلاین ممکن است هزینه API داشته باشد. مصرف و سقف هزینه را در داشبورد ارائه‌دهنده کنترل کنید.
- در صورت نبود اتصال، برنامه به دستیار آفلاین فعلی برمی‌گردد.
