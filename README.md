# آموزش با امیر — سامانه یادگیری و مدیریت کلاس

نسخه هدف بعدی مخزن: **3.2.1**  
وب‌اپ: https://amiraammiirr1000-ai.github.io/amoozesh-ba-amir/

## وضعیت این مرحله

### صفحه خانه و پوشه‌بندی نسخه ۲.۹.۹
- بازطراحی صفحه اول با چیدمان خلوت‌تر، کارت‌های پوشه‌ای، شروع سریع و نمایش آمار یادگیری.
- ایجاد کتابخانه دسته‌بندی‌شده برای درس‌ها، پایه‌ها، انگلیسی، کاربرگ و PDF، بازی‌ها، ابزارها، مدیریت کلاس و پروفایل.
- حفظ بخش‌های قبلی درس‌ها، نقشه کتاب و آمار؛ محتوای ریاضی ششم در بخش بازشونده جدا قرار گرفته تا صفحه اول شلوغ نباشد.
- اضافه شدن میانبر «پوشه‌ها» به نوار پایین و دسته‌بندی واکنش‌گرا برای موبایل و تبلت.
- پوشه‌ها در این نسخه دسته‌بندی رابط کاربری هستند؛ هنوز فضای ذخیره‌سازی ابری مشترک برای فایل‌های آپلودی وجود ندارد.


### بازطراحی ناوبری، پایه‌های ۱ تا ۵، ویدئو و کلاس آنلاین
- نوار ثابت بالای صفحه با ذره‌بین جست‌وجو و منوی سه‌نقطه؛ جست‌وجوی سراسری در همه نماها.
- صفحه خانه پوشه‌محور با مسیر مستقل پایه‌ها، انگلیسی، کاربرگ، بازی، کلاس، ویدئو و حساب کاربری.
- برای پایه‌های اول تا پنجم، ۸ مبحث ریاضی مکمل در هر پایه (۴۰ مبحث در مجموع)، هرکدام با هدف، مثال حل‌شده، روش کار و سه تمرین تعاملی.
- آزمون جامع ۱۶ سؤالی و کاربرگ چاپی ۲۴ سؤالی با پاسخ‌نامه آموزگار برای هر پایه؛ پیشرفت و نتیجه آزمون در حافظه محلی ذخیره می‌شود.
- کتابخانه ویدئو با پیوند امن آپارات/YouTube/Vimeo/فایل HTTPS و پخش موقت فایل ویدئویی از گوشی.
- صفحه کلاس‌های آنلاین بر اساس نقش؛ دانش‌آموز می‌تواند با کد دعوت عضو شود و پیوند جلسه معلم را ببیند.
- فایل visual-polish-v18.css برای یکپارچه‌سازی ظاهر، کارت‌ها، دکمه‌ها، فرم‌ها، حالت تیره و کاهش حرکت.
- داده‌های جدید درس‌های پایه‌های اول تا پنجم، آزمون‌ها، فهرست ویدئو و داده‌های انگلیسی به پشتیبان JSON محلی افزوده شده‌اند.
- پیشرفت پایه‌های اول تا پنجم، آزمون و کاربرگ برای هر حساب جداگانه ذخیره می‌شود؛ همگام‌سازی ابری این بخش هنوز تکمیل نشده است.

**محدودیت محتوای پایه‌ها:** این ۴۰ مبحث محتوای مکمل تألیفی هستند؛ هنوز پوشش کامل فصل‌ها و صفحه‌های آخرین کتاب رسمی و همه درس‌های غیرریاضی پایه‌های اول تا پنجم تکمیل نشده است. برای پایه‌های اول و دوم، کتاب‌های ریاضی سال تحصیلی ۱۴۰۵–۱۴۰۶ در دو جلد عرضه شده‌اند؛ تطبیق دقیق هر دو جلد در مرحله بعد انجام می‌شود.

### ریاضی ششم
- ساختار ۷ فصل و ۲۹ درس مستقل مطابق نقشه آموزشی برنامه.
- برای هر ۲۹ درس: هدف یادگیری، مثال حل‌شده، روش حل، خطای رایج و سه تمرین سطح‌بندی‌شده با پاسخ تشریحی تکمیلی.
- آزمون درس و آزمون فصل، ثبت پیشرفت، امتیاز و کارنامه.
- ۸ بازی تعاملی با دورهای ۱۰ سؤالی، راهنما، امتیازدهی، ذخیره آمار هر بازی و آزمون runtime خودکار.
- کاربرگ‌ساز برای ۱۱ موضوع: الگوها، ارزش مکانی، بخش‌پذیری، اعداد صحیح، کسر، اعشار، تقارن، مختصات، اندازه‌گیری، تناسب/درصد و تقریب.
- کاربرگ در اندازه‌های ۵، ۱۰ و ۱۵ سؤال، سطح آسان/متوسط/چالشی و کلید پاسخ قابل چاپ یا ذخیره PDF.
- تخته سفید لمسی و ابزارهای معلم.

### استودیوی زبان انگلیسی
- ۸ درس مکمل تألیفی برای هر مسیر انتخابی First Friends 1–3 و Family and Friends 1–6.
- هر درس: ۶ واژه با معنی و مثال، نکته گرامری، الگوی جمله، مکالمه، متن خواندن، ۳ پرسش درک مطلب، تمرین نوشتاری و تمرین شنیداری/گفتاری.
- مسیرهای First Friends و Family and Friends تا B1، به‌علاوه دو مسیر مستقل تألیفی B2 و Advanced C1 با ۸ درس جدید، گرامر پیشرفته، متن تحلیلی و تمرین نوشتاری سطح بالا.
- دیکشنری انگلیسی–فارسی با جست‌وجو، ذخیره واژه‌های منتخب و تلفظ.
- صدای en-US دستگاه، انتخاب صدای موجود و تنظیم سرعت پخش؛ کیفیت و دسترس‌پذیری صدا وابسته به گوشی/مرورگر است.
- ذخیره نوشته‌ها، نمره آزمون و تکمیل درس روی همان دستگاه.
- کاربرگ هر Unit قابل چاپ و ذخیره به PDF از طریق پنجره چاپ مرورگر.

**محدودیت حقوق نشر:** فایل کامل تجاری PDF و صوت کتاب‌های Oxford داخل مخزن کپی نشده است. کاربر می‌تواند نسخه دارای مجوز یا خریداری‌شده خود را در کتابخانه محلی برنامه باز کند. درس‌های داخل استودیو محتوای مکمل و تألیفی‌اند و ادعا نمی‌شود که ترتیب رسمی Unitهای Oxford را بازتولید می‌کنند.

### حساب‌ها و مدیریت کلاس
- نقش دانش‌آموز، معلم و مدیر؛ درخواست معلم نیازمند تأیید مدیر است.
- دعوت دانش‌آموز به کلاس با کد، فهرست دانش‌آموزان کلاس و گزارش پیشرفت.
- همگام‌سازی پیشرفت ریاضی دانش‌آموز با Supabase از طریق RPC محدود به حساب خودش؛ معلم فقط گزارش کلاس خودش را می‌خواند.
- RLS و بررسی مالکیت کلاس در گزارش معلم.
- مدیریت جلسه، لینک Meet/Zoom و حضور و غیاب در ابزارهای معلم.

### تابلوی پیشرفت گروهی A3
- تابلوی قابل تنظیم برای ۱ تا ۱۲ گروه با فیلدهای باز مدرسه، آموزگار، پایه، کلاس و سال تحصیلی.
- ۹ ماه تحصیلی و ۴ هفته در هر ماه؛ برای هر هفته محل ثبت تاریخ و نمره وجود دارد.
- نقش‌های سرگروه، جانشین و زیرگروه‌های A/B/C؛ امتیاز کل، میانگین هر گروه و رتبه‌بندی خودکار.
- چاپ در اندازه A3 افقی و پشتیبان‌گیری/بازیابی JSON.
- اطلاعات هر حساب جداگانه روی همان دستگاه ذخیره می‌شود؛ همگام‌سازی ابری این تابلو هنوز اضافه نشده است.

## محدودیت‌هایی که هنوز باید تکمیل شوند
- پوشش کامل فصل‌ها و صفحه‌های کتاب رسمی پایه‌های اول تا پنجم و محتوای درس‌های غیرریاضی این پایه‌ها هنوز تکمیل نشده است؛ فعلاً برای هر پایه ۸ مبحث ریاضی مکمل فعال است.
- فایل‌های اصلی و تجاری Oxford به دلیل حق نشر همراه برنامه نیستند.
- جلسه تصویری داخل برنامه میزبانی نمی‌شود؛ از لینک Meet/Zoom استفاده می‌شود.
- دستیار هوشمند زنده فقط پس از راه‌اندازی سرور و تنظیم کلید API معتبر فعال می‌شود؛ در نبود آن نباید آن را سرویس هوش مصنوعی آنلاین تلقی کرد.
- خروجی Release امضاشده با کلید دائمی در Workflow مستقل ساخته می‌شود؛ پیش از انتشار فروشگاهی هنوز تست دستگاه واقعی، تکمیل حریم خصوصی و تصاویر واقعی فروشگاه لازم است.
- تست خودکار جایگزین تست کامل روی گوشی واقعی، حساب‌های واقعی معلم/دانش‌آموز و آزمون دسترس‌پذیری نیست.

## کنترل کیفیت

با Node.js نسخه ۲۰ یا ۲۲:

```bash
npm install
npm run qa
npm --prefix secure-ai-server install
npm --prefix secure-ai-server test
```

مجموعه QA ساختار صفحات، همگام بودن فایل‌های وب و اندروید، نقش‌ها و RPCها، بانک درس‌ها، بازی‌ها، کاربرگ‌ها، محتوای زبان، نحو جاوااسکریپت و چند آزمون runtime را بررسی می‌کند.

## ساخت و انتشار
- وب‌اپ از GitHub Pages منتشر می‌شود.
- Workflow اندروید در GitHub Actions با نام **Android Debug APK** خروجی Debug می‌سازد.
- APK آزمایشی با نسخه انتشار فروشگاهی امضاشده یکسان نیست.
- انتشار در کافه‌بازار بعد از تست نهایی و ساخت نسخه Release انجام می‌شود.


### ارتقای نسخه ۳.۲.۰
- نشان جدید کتاب گشوده و ستاره طلایی در `icon.svg`؛ فایل‌های وب و ریشه همگام هستند.
- مرکز ارتباط با ما با پیوند به اینستاگرام رسمی و وب‌اپ.
- فرم پیشنهادات و انتقادات با ذخیره محلی، ارسال آنلاین مشروط به ورود و اجرای فایل backend/support-feedback-v1.sql، صندوق مدیر کل و خروجی JSON؛ در نبود زیرساخت آنلاین، اشتراک‌گذاری دستی فعال است.
- طرح‌های دسترسی رایگان، یادگیرنده پلاس و معلم حرفه‌ای به‌صورت معرفی؛ هیچ پرداخت یا اشتراک پولی فعال نیست.
- سیاست حریم خصوصی در برنامه و نشانی عمومی `/privacy.html`؛ متن فعلی اولیه است و پیش از انتشار باید با جریان داده واقعی و بررسی حقوقی تطبیق داده شود.
- نسخه هدف اندروید ۳.۲.۰ و versionCode برابر ۴۲؛ امضای انتشار باید با keystore دائمی موجود حفظ شود.
- فهرست توضیحات فروشگاه و چک‌لیست انتشار در `STORE-LISTING-FA.md`.
