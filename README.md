# آموزش با امیر — سامانه یادگیری و مدیریت کلاس

نسخه جاری مخزن: **2.9.4**  
وب‌اپ: https://amiraammiirr1000-ai.github.io/amoozesh-ba-amir/

## وضعیت این مرحله

### ریاضی ششم
- ساختار ۷ فصل و ۲۹ درس مستقل مطابق نقشه آموزشی برنامه.
- برای هر ۲۹ درس: هدف یادگیری، مثال حل‌شده، روش حل، خطای رایج و سه تمرین سطح‌بندی‌شده با پاسخ تشریحی تکمیلی.
- آزمون درس و آزمون فصل، ثبت پیشرفت، امتیاز و کارنامه.
- ۸ بازی تعاملی با دورهای ۱۰ سؤالی، راهنما، امتیازدهی، ذخیره آمار هر بازی و آزمون runtime خودکار.
- کاربرگ‌ساز برای ۱۱ موضوع: الگوها، ارزش مکانی، بخش‌پذیری، اعداد صحیح، کسر، اعشار، تقارن، مختصات، اندازه‌گیری، تناسب/درصد و تقریب.
- کاربرگ در اندازه‌های ۵، ۱۰ و ۱۵ سؤال، سطح آسان/متوسط/چالشی و کلید پاسخ قابل چاپ یا ذخیره PDF.
- تخته سفید لمسی و ابزارهای معلم.

### استودیوی زبان انگلیسی
- ۸ درس مکمل تألیفی برای هر مسیر انتخابی First Friends 1–3 و Family and Friends 1–6.
- هر درس: ۶ واژه با معنی و مثال، نکته گرامری، الگوی جمله، مکالمه، متن خواندن، ۳ پرسش درک مطلب، تمرین نوشتاری و تمرین شنیداری/گفتاری.
- مسیرهای شش‌سطحی از Starter A1 تا B1 با گسترش گرامر، نمونه و تمرین متناسب با سطح.
- دیکشنری انگلیسی–فارسی با جست‌وجو، ذخیره واژه‌های منتخب و تلفظ.
- صدای en-US دستگاه، انتخاب صدای موجود و تنظیم سرعت پخش؛ کیفیت و دسترس‌پذیری صدا وابسته به گوشی/مرورگر است.
- ذخیره نوشته‌ها، نمره آزمون و تکمیل درس روی همان دستگاه.
- کاربرگ هر Unit قابل چاپ و ذخیره به PDF از طریق پنجره چاپ مرورگر.

**محدودیت حقوق نشر:** فایل کامل تجاری PDF و صوت کتاب‌های Oxford داخل مخزن کپی نشده است. کاربر می‌تواند نسخه دارای مجوز یا خریداری‌شده خود را در کتابخانه محلی برنامه باز کند. درس‌های داخل استودیو محتوای مکمل و تألیفی‌اند و ادعا نمی‌شود که ترتیب رسمی Unitهای Oxford را بازتولید می‌کنند.

### حساب‌ها و مدیریت کلاس
- نقش دانش‌آموز، معلم و مدیر؛ درخواست معلم نیازمند تأیید مدیر است.
- دعوت دانش‌آموز به کلاس با کد، فهرست دانش‌آموزان کلاس و گزارش پیشرفت.
- همگام‌سازی پیشرفت ریاضی دانش‌آموز با Supabase از طریق RPC محدود به حساب خودش؛ معلم فقط گزارش کلاس خودش را می‌خواند.
- RLS و بررسی مالکیت کلاس در گزارش معلم.
- مدیریت جلسه، لینک Meet/Zoom و حضور و غیاب در ابزارهای معلم.

## محدودیت‌هایی که هنوز باید تکمیل شوند
- محتوای آموزشی کامل پایه‌های اول تا پنجم و سایر درس‌ها هنوز در این نسخه تحویل نشده است؛ فعلاً محتوای عمیق ریاضی برای پایه ششم و مسیر مکمل زبان آماده شده است.
- فایل‌های اصلی و تجاری Oxford به دلیل حق نشر همراه برنامه نیستند.
- جلسه تصویری داخل برنامه میزبانی نمی‌شود؛ از لینک Meet/Zoom استفاده می‌شود.
- دستیار هوشمند زنده فقط پس از راه‌اندازی سرور و تنظیم کلید API معتبر فعال می‌شود؛ در نبود آن نباید آن را سرویس هوش مصنوعی آنلاین تلقی کرد.
- APK فعلی خروجی Debug است و برای انتشار فروشگاهی به نسخه Release امضاشده، سیاست حریم خصوصی، تصاویر فروشگاه و آزمون دستگاه واقعی نیاز دارد.
- تست خودکار جایگزین تست کامل روی گوشی واقعی، حساب‌های واقعی معلم/دانش‌آموز و آزمون دسترس‌پذیری نیست.

## کنترل کیفیت

با Node.js نسخه ۲۰ یا ۲۲:

```bash
npm install
npm run qa
npm --prefix secure-ai-server install
npm --prefix secure-ai-server test
```

مجموعه QA ساختار صفحات، همگام بودن فایل‌های وب و اندروید، نقش‌ها و RPCها، بانک درس‌ها، بازی‌ها، کاربرگ‌ها، محتوای زبان، نحو جاوااسکریپت و چند آزمون runtime را بررسی می‌کند.
