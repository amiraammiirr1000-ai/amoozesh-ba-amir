# آموزش با امیر — نسخه ۱.۲

اپ آموزشی فارسی، راست‌چین و موبایل‌محور با قابلیت نصب به‌صورت PWA و پیکربندی اولیه اندروید.

## محتوای فعلی
- درس‌نامه‌های تألیفی فصل اول ریاضی ششم: الگوهای عددی، عددنویسی، بخش‌پذیری و اعداد صحیح
- آزمون، بانک پرسش، ثبت پیشرفت، کاربرگ‌ساز، وایت‌برد لمسی و دفتر یادداشت
- پنل محلی معلم، خروجی CSV/JSON و پشتیبان‌گیری
- صفحه «درباره ما»، تصویر آموزشی، سه تم و فونت فارسی Vazirmatn
- دستیار آفلاین و اتصال اختیاری به بک‌اند امن OpenAI Responses API

## نکته مهم درباره وضعیت محصول
این نسخه یک برنامه وب/PWA و پروژه آماده تولید APK آزمایشی است؛ APK امضاشده و انتشار عمومی هنوز ساخته نشده‌اند. داده‌های کلاس فعلاً در مرورگر/دستگاه محلی ذخیره می‌شوند و حساب دانش‌آموز، همگام‌سازی ابری و پرداخت آنلاین وجود ندارد. محتوای فصل‌های ۲ تا ۷ هنوز درس‌نامه کامل و آزمون مستقل ندارد. قبل از ادعای انطباق صفحه‌به‌صفحه، PDF رسمی چاپ ۱۴۰۵–۱۴۰۶ را در `https://chap.sch.ir` بازبینی کنید.

## بررسی کیفیت محلی
با Node.js نسخه ۲۰ یا ۲۲:

```bash
npm install
npm run qa
npm --prefix secure-ai-server install
npm --prefix secure-ai-server test
```

## فعال‌سازی دستیار هوشمند آنلاین (استقرار Render)

**کلید OpenAI را داخل HTML، APK، GitHub یا گفت‌وگو قرار ندهید.** کلید فقط باید در متغیر محیطی خصوصی میزبان باشد. هزینه مصرف API جدا از اشتراک ChatGPT است و باید سقف بودجه/هشدار مصرف را در حساب API تنظیم کنید.

1. پروژه را در یک مخزن خصوصی GitHub بارگذاری کنید. فایل `render.yaml` در ریشه، سرویس بک‌اند را از پوشه `secure-ai-server` تعریف می‌کند.
2. در Render از گزینه ساخت سرویس با Blueprint استفاده و مخزن را انتخاب کنید.
3. در متغیرهای محیطی سرویس، `OPENAI_API_KEY` را با کلید API خودتان مقداردهی کنید. این مقدار را در چت یا کد قرار ندهید. `TUTOR_ACCESS_TOKEN` باید یک راز تصادفی حداقل ۳۲ نویسه باشد؛ Render می‌تواند آن را تولید کند.
4. `APP_ORIGIN` را با مبدأ دقیق برنامه تنظیم کنید. برای اپ Capacitor معمولاً `https://localhost` یا `capacitor://localhost` مطرح است؛ اگر PWA را روی دامنه‌ای منتشر کردید، مبدأ همان دامنه را نیز اضافه کنید. CORS جایگزین احراز هویت نیست.
5. پس از انتشار، نشانی `https://.../health` را باز کنید. باید `ok: true`, `configured: true` و `accessProtected: true` دیده شود. `configured: true` فقط وجود کلید در محیط را نشان می‌دهد و تضمین نمی‌کند کلید معتبر یا دارای اعتبار مالی باشد.
6. در برنامه، نشانی پایه سرویس را بدون `/api/tutor` وارد و ذخیره کنید. سپس توکن دسترسی خصوصی را در بخش معلم هوشمند وارد کنید و «آزمایش اتصال» را بزنید. برای آزمایش واقعی، یک سؤال بفرستید.
7. هرگز توکن خصوصی را در مخزن عمومی منتشر نکنید. این سازوکار برای بتای محدود است؛ برای انتشار عمومی به حساب کاربری واقعی، سهمیه/هزینه برای هر کاربر و حفاظت بیشتر نیاز داریم.

### اجرای محلی بک‌اند

```bash
cd secure-ai-server
npm install
# متغیرهای محیطی را در ترمینال/مدیریت اسرار تنظیم کنید؛ فایل واقعی .env را commit نکنید.
npm start
```

## ساخت APK آزمایشی

Workflow موجود در `.github/workflows/android-debug-apk.yml` پس از بارگذاری مخزن در GitHub، از مسیر **Actions → Build Android debug APK → Run workflow** اجرا می‌شود. خروجی در بخش Artifacts همان اجرای Workflow قرار می‌گیرد. این APK برای آزمایش است، نه انتشار نهایی. برای انتشار عمومی باید امضای release و آزمون روی دستگاه واقعی انجام شود.

## حریم خصوصی و محدودیت‌ها
- پیشرفت، عکس پروفایل و داده‌های پنل معلم فعلاً روی دستگاه ذخیره می‌شوند.
- پرسش‌های ارسالی به سرور هوش مصنوعی به ارائه‌دهنده API ارسال می‌شوند؛ برای دانش‌آموزان، اطلاع‌رسانی و رضایت والدین/مدرسه را در نظر بگیرید.
- سرور درخواست‌ها را محدود می‌کند و از `store: false` استفاده می‌کند، اما پیش از استفاده عمومی، تست امنیتی و سیاست حریم خصوصی کامل لازم است.
